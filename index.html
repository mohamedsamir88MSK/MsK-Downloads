قد تخضع زيارة GitHub أو تنزيل الملفات لسياسات الخصوصية وشروط الخدمة الخاصة بـ GitHub.

هذه المعلومات تخص صفحة الويب فقط، ولا تمثل وصفًا كاملًا لأذونات التطبيق أو البيانات التي قد يعالجها بعد تثبيته.
